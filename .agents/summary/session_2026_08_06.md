### Hệ thống Toast Notification Toàn cục (Global Notification System)
- Tạo Context & Provider [NotificationContext.tsx](file:///f:/Coding/Project/sowfkun.verse.v2/sowfkun-verse-web/src/context/NotificationContext.tsx) quản lý thông báo Toast ở góc dưới bên phải.
- **Giới hạn & Hàng đợi (Queue)**: Hiển thị tối đa 3 thông báo đồng thời. Các thông báo thừa được đưa vào hàng chờ xếp chồng và tự động trượt ra thay thế lần lượt mỗi khi có thông báo cũ biến mất.
- **Tách biệt vòng đời (ToastItem)**: Chuyển giao quản lý timeout tự tắt (4 giây) cho từng component `ToastItem` con để sửa triệt để lỗi reset/chớp timer khi re-render.
- **CSS color-mix & Trong suốt**: Màu nền và màu viền của Toast pha trộn màu trạng thái (xanh/đỏ/cam/xanh dương) với nền tối trong suốt `rgba(11, 15, 25, 0.8)` thông qua hàm `color-mix`, làm nổi bật sắc thái trạng thái nhưng vẫn giữ hiệu ứng kính mờ trong suốt (`backdrop-blur-md`).
- **Giao diện tối giản**: Loại bỏ icon và số index kiểm thử, chỉ giữ lại text thông báo và nút đóng X đồng màu text.

### Kiến trúc Gọi API & Bắt lỗi Toàn cục (Event-Driven API Error Handling)
- Tích hợp cơ chế phát sự kiện toàn cục `'api-error'` từ `apiFetch` ([client.ts](file:///f:/Coding/Project/sowfkun.verse.v2/sowfkun-verse-web/src/lib/api/client.ts)) khi API thất bại hoặc kết nối sập.
- `NotificationProvider` tự động bắt event này và đẩy Toast lỗi thô hiển thị (Backend đã dịch đa ngôn ngữ sẵn trong response message).
- **Linh hoạt cấu hình lỗi**:
  - Hỗ trợ tùy chọn `{ skipToastOnError: true }` cho phép tắt Toast lỗi toàn cục, phục vụ việc tự bắt và xử lý giao diện lỗi riêng ở từng trang.
  - Tất cả API wrapper (`login`, `register`, v.v.) và context đều hỗ trợ truyền tham số `options?: ApiOptions` để chuyển tiếp cấu hình lỗi này từ ngoài vào.
- **Lỗi mạng không có Response**: Tự động phát hiện lỗi fetch, check ngôn ngữ hiện tại của trình duyệt để hiển thị thông báo kết nối thân thiện (*"Không thể kết nối đến máy chủ API"* / *"Cannot connect to API server"*).
- **Dọn dẹp log console**: Xóa bỏ toàn bộ các lệnh `console.error` và không quăng exception thô gây crash trang, đảm bảo console trình duyệt sạch đẹp 100%.
